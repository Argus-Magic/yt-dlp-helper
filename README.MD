
# YouTube DLP Helper

This is a passion project that i started because quite frankly, the baseline for downloading youtube videos was too much of a pain. I wanted to make it as easy as possible to download the audios.
It began as a .txt file which i would straight up copy and paste on the CLI each time i wanted to download something. That turned into a "What if i could do that in one click?".
That txt file quickly turned into a .bat file and i did some experimentation [^1] and when the batch file was eventually done it looked too ugly in my desktop so i asked how to give it an icon and the simplest answer was turning it into an .exe file.
Finally thats where i am rn. Maybe in the future i will add a GUI to make it even more user friendly and publish it on github.

[^1]: Trying to making it on my own, getting like 95% done and failing to work out the kinks of batch files and finally asking an AI for help.
